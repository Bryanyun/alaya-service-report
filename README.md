# Alaya Service Report

Published static interface for the Alaya service-report plugin.

Website: https://bryanyun.github.io/alaya-service-report/

Open this URL from the Alaya plugin menu. Reports, equipment, actions and sales-agent assignments are stored in Alaya. This repository contains only compiled public interface files, not business records or credentials.

The source repository is maintained separately. To update this site, build the current source with npm run build:github and publish the generated render/dist files here.
